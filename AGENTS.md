# Standard Agent Instructions

> This block is managed by `proj init`. It is re-applied (not duplicated)
> on every init. Edit this file (`templates/AGENTS_STANDARD.md`) to change
> what all new projects get. Project-specific notes live below it under
> `## Project-Specific Instructions` in `AGENTS.md`.

- Read `README.md` before making significant changes.
- Check `TODO.md` for current tasks; update it when a task's status changes.
- Add durable, reusable discoveries to `KNOWLEDGE.md` (no ephemeral logs).
- Run `proj check` (or the project's own test/lint commands) before marking a task done.
- Keep Git commits focused; never commit secrets.
- Do not rewrite Git history unless explicitly instructed.
- Prefer editing existing files over creating new ones.
